---
title: Testnets
description: Try Kite with test tokens, on a server that can never take real payments.
---

Run a separate server with `KITE_IS_TESTNET=true` and its own database to try Kite without real funds.

- A testnet server only offers testnets when you add a chain, and a mainnet server only offers mainnets. Test tokens can never pay a real payment link.
- Every page of a testnet server, the checkout and sign-in included, shows a banner saying it's a testnet instance, with **Learn more** explaining that its funds have no real value.
- Switching the flag on an existing database hides the other kind of chains rather than deleting them.
- Everything else works the same: providers, the dashboard, the API, webhooks and the packages. The exception is [payouts](/payments/payouts): NEAR Intents has no testnet, so a testnet server settles every payment on the chain it was paid on.

The testnets a server can offer are the entries marked `testnet` in the server's [chain registry](https://github.com/Kite-01/server/blob/main/src/shared/chains/registry.ts).

As on mainnet, [deploy your own Kite factory](/contracts/overview#deploying-a-factory) on each testnet you use, with your server's operator wallet as its operator.

## Getting test tokens

On Base Sepolia and a couple other chains, Circle's faucet gives test USDC, and most faucets give test ETH for deploying your factory.
